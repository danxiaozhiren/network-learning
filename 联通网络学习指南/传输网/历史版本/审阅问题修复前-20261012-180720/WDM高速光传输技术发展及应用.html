WDM 高速光传输
技术发展及应用

光纤已经铺好，怎样让更多数据一起通过？

从 A 机房到 B 机房，看多路光怎样共纤、途中怎样放大，以及中间站怎样接入业务。前一课：模块里的多路光

01　一根光纤，承载多路光

A、B 之间已有光纤，业务却越来越多。业务就是需要送到另一端的数据。可以增加光纤，也可以在现有光纤上同时传送多路光。

波分复用（WDM）让不同波长的光信号共用一根光纤。波长是光波一个周期的长度；这里用 λ₁、λ₂ 等区分不同光通道。光通道就是可在光纤里按波长单独分出、承载数据的一路光。

增加波长是增加同时工作的光通道；提高单波速率是让其中一路每秒传更多数据。二者可以结合。4 路各 400G，合计就是 1.6 Tb/s，即每秒 1.6 万亿比特。

前一课 LR4 的四个波长共同组成一条 100G 业务；这里比较的是线路光通道。实际网络还可以把多条业务组织到一个光通道里，下一课再讲。

02　从 A 到 B，光经过什么

A 端先把数据放到指定波长的光上，合波器（MUX）把多路光接入同一根光纤。B 端的分波器（DEMUX）按波长把它们分开，再交给对应接收端恢复数据。

合波、分波只安排光怎样通过；把电信号变成光、从光中读回数据，由收发设备完成。

03　光变弱了，怎样继续传

光在光纤和连接处会损失能量，叫衰减。距离越长，接收端可能收到过弱的光。掺铒光纤放大器（EDFA）利用加入铒元素的光纤放大光，可同时增强其工作波段内的多路信号。

放大器也会放大已有噪声——干扰信号判读的随机变化——并增加自身噪声。所以，光更强以后，数据仍可能读不准。

光放大：直接增强光

信号直接以光的形式通过，放大器不读取其中的 0、1。适合补偿光损耗，减少逐路转换处理。

光电再生：读出后重新发

再生先把光转成电、恢复数据，再形成新的发送光。它需要对应收发和处理资源；接收端已无法恢复的数据，也不能凭空补回。

高速线路要同时核对光功率（光有多强）和信号质量。功率合适只是其中一项；波形失真和噪声过大，也会限制距离。回看 FEC 纠错与 DOM 监测 →

04　经过 C 站，哪些光留下来

线路经过 C 机房。λ₁ 要继续去 B；λ₂ 的数据要在 C 使用。把光通道从线路取出，叫下波；把本站发出的光通道加入线路，叫上波。

可重构光分插复用器（ROADM）是能远程调整这些连接的光节点：让指定光通道直通、接到本站，或从本站加入线路。多方向节点还可把光通道转向另一条光线路。

这一步调度的是整条光通道。如果只想从其中取出某一条小业务，就需要进一步的业务组织与交换；下一课的光传送网（OTN）会讲怎样组织和转接这些业务。

05　高速演进，改变了哪几件事

每个光通道都占用一定范围的光频谱，也就是一段光频率范围。频率表示光每秒振动多少次，与波长描述的是同一束光的不同参数；频隙是分配给一个光通道的连续频率范围。它的宽度与数据速率采用不同单位。

01

每个符号带更多信息

符号是一次发送选出的信号状态。更复杂的调制（按数据改变信号）让每个符号携带更多比特（0 或 1），能在相近频谱里提高速率；状态更密，也更怕噪声。

相干接收把收到的光与参考光一起检测；DSP（数字信号处理）再补偿部分失真，帮助恢复数据。回看相干接收 →

02

每秒发更多符号

每秒发送多少个符号叫波特率。提高波特率，也能提高单波速率；通常需要更宽的光频谱，以及相应的发送、接收和处理能力。

03

给不同信号安排合适的空间

灵活网格可按设备支持的基本间隔分配不同宽度，让占用频谱不同的信号共存。

同一套设备在不同线路上，最高可用速率可能不同。距离增加、经过节点增多，信号条件会变化；因此需要在单波速率、占用频谱和传送距离之间取舍。

C、L 波段扩展，扩的是什么？

波段是一段波长范围。C 波段和相邻的 L 波段是光通信使用的两个波段。已有 C 波段拥挤时，支持 C+L 的系统可利用更多光频谱、安排更多通道；放大器、滤波器和沿途节点都要配套支持。

06　按任务选择线路

粗波分（CWDM）把波长隔得较宽，标准相邻间隔为 20 nm（纳米，长度单位）。密集波分（DWDM）把光通道安排得更密，适合在有限频谱中容纳更多通道。

CWDM、DWDM 描述通道怎样安排；具体速率、距离和开通数量，还要看收发器件与整条线路。

园区互联：通道不多、线路简单

CWDM 加无源合分波器可作为候选，减少新铺光纤的需求。重点核对两端波长、光口和整条链路损耗。

城域多站：业务经常增加、改去向

DWDM 配合 ROADM，让不同光通道共纤，并可远程调整上下波与连接。重点核对沿途频隙、端口及信号条件。

数据中心互连：少量光纤承载大容量

高速相干光通道配合 WDM 线路，提高单波和整纤容量。重点核对单波速率、频谱、线路损耗及放大配置。

长途干线：距离长、经过站点多

用合适的 DWDM 线路、光放大与接收处理持续传送；必要时安排光电再生。重点平衡速率与距离，逐段核对信号质量。
