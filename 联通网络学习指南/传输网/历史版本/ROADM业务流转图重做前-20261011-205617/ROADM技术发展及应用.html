ROADM 技术发展及应用

同一根光纤里的多路光，到了 C，分别该往哪里走？

甲从 A 送到 B，乙可以在 C 接收，也可以改去 D。先看整路光怎样调度，再看它与 OTN 的区别。回看上一课：按 ODU 转接业务

01　业务要改目的地，整路光怎样改接？

A、B 之间经过 C 机房。A 要送出的两路数据叫两条业务：甲去 B，乙的目的地会随需求变化。在本节主图中，它们分别使用一条光通道，也就是能在光纤中单独分出、承载数据的一路光。

两条光通道采用不同波长——光波一次重复的长度，用 λ₁、λ₂ 区分。波分复用（WDM）把不同波长的光合到同一根光纤。C 若使用固定连接，改变某一路光的去向，往往要现场改接跳纤（设备之间用于连接的短光纤）或器件。

可重构光分插复用器（ROADM）让 C 这样的节点（连接、转接光线路的站点）能通过配置，选择各光通道的出口：继续走、交给本站，或者转向另一条已连接的线路。这里的“可重构”就是可以重新安排光连接。

λ₂ · 业务乙

主图让每条业务独占一个光通道，便于看清去向。同一光通道也可以承载多条业务，第四节再换成这个条件。

02　C 站里，谁把光送到对应出口？

ROADM 是节点的光调度功能，常见实现以波长选择开关（WSS）为核心光器件。WSS 按波长选择光通道，把它们接到指定光端口；光端口就是连接光纤、让光进出的接口。

配置由网管或控制系统下发。直通的光经过光学路径继续传送；要在 C 使用的数据，则先把对应光引到本站接收机，由接收机完成光电转换，把携带数据的光信号还原为设备能处理的电信号。

“三维、四维 ROADM”里的“维”是什么？

它通常指节点的线路方向数。C 分别连接 A、B、D，就是三个线路方向。这里数的是面向相邻节点的线路连接，不是机框上的插口总数。双向传送通常分别使用收、发光纤，本课只展开 A 发出的一个方向。

03　甲一直到 B，只改变 λ₂ 的出口

直通让输入光通道继续进入输出线路；下波把输入光通道引到本站接收机；上波把本站发射机产生的新光加入输出线路。多方向节点还可以把光通道改接到另一条线路。

点选四种配置，看清旧光在哪里结束、新光从哪里进入。λ₁ 的甲始终继续去 B。

同一个 λ₂，为什么可以先下波，再上波？

A 发来的 λ₂ 在 C 接收机处终止。C 的发射机再用 λ₂ 发出另一条新光通道，送往 B；两段线路承载的可以是不同数据。输出上只有 C 的新光，旧光没有同时混入。

如果 A 的 λ₂ 仍在直通，就不能再把独立的另一束 λ₂ 加入同一输出光纤、占用重叠频谱。必须先安排互不冲突的光连接。

04　甲、乙在同一光通道里，还能分别改接吗？

现在改变条件：甲、乙共用同一个 λ₁ 光通道，甲仍要到 B，乙要交给 C。ROADM 可以把整个 λ₁ 下到 C，但它不能从光通道内部单独挑出乙。

本例两条业务各自装入一个光通道数据单元（ODU），再共用 λ₁。ODU 是承载业务数据、附带监测信息的数字单元；甲、乙分别在 ODU 甲和 ODU 乙 中。

C 先接收光、恢复数字信号，再由支持业务交换的光传送网（OTN）分别处理。OTN 按规定的数字格式组织、传送和监测业务；按 ODU 分别转接，叫OTN 电交叉。甲送到去 B 的线路，乙交给 C 的客户接口。

调度对象整条光通道或对应频谱范围。业务所在的 ODU 数字单元。

两种功能可以集成在同一设备或同一站点。选择哪一种，看需要调整的是整路光，还是光通道里的某条业务。

05　上下波多了，还会遇到哪些限制？

线路方向和光通道增多后，限制可能来自站内的上下波连接结构。CDC是三种能力的合称：无色、无方向、无竞争。它们分别解除端口绑定和站内阻塞，不是每套 ROADM 都同时具备。

无色Colorless

上下波端口不固定绑定某一个波长。一个端口可以按配置服务不同波长，减少为换波长而改跳纤。

这是端口不绑波长；实际发射波长仍由发射机等决定，不是 WSS 把光变了色。

无方向Directionless

上下波端口不固定绑定某个已连接的线路方向。例如同一个本站发射端口，可以配置到去 B 或去 D 的线路。

它解除的是本站上下波端口的方向绑定。没有铺设线路的方向，仍然去不了。

无竞争Contentionless

站内结构允许相同波长的不同光通道，经不同端口、不同方向同时上下波，不因站内共用结构而互相阻塞。

两个独立信号若在同一输出光纤占用重叠频谱，仍会冲突。

灵活栅格：为不同宽度的信号安排频谱

频谱在这里指可用于传光信号的频率范围。频隙是为一条光通道预留的一段范围；栅格规定通道中心位置和频隙宽度怎样取值。

固定栅格按固定的中心频率间隔规划通道。灵活栅格（Flex grid）允许按规定单位选择不同宽度的频隙，让较窄和较宽的信号在同一线路上共存。各通道预留的范围不能重叠。

它调整的是频谱分配，不会自动提高客户业务速率。沿途 WSS、收发设备和规划系统需要支持对应宽度，并核对实际可用频谱。

06　什么场景值得用 ROADM？

城域与区域网络

光通道经常改接

节点多，需要开通、下波或调整整路光的去向。ROADM 通过配置改变光连接，减少每次到现场改跳纤的工作。

若只有少量固定的 A→B 通道，长期不改接，固定合分波方案也可能满足需求。
多方向汇聚节点

上下波端口多

C 同时面向多个相邻站点，业务变化频繁。按实际限制选择无色、无方向或 CDC 架构，降低站内端口绑定和阻塞。

需要从同一光通道里分别调度小业务时，配合 OTN 电交叉。
高速通道共存

频谱宽度不同

不同速率和实现方式的信号可能需要不同频谱宽度。匹配的灵活栅格设备能按需预留频隙，避免把所有通道都按同一宽度安排。

速率相同也不意味着频谱占用相同；应核对收发设备的实际要求。
断纤后，能否自动改走另一条路？

ROADM 提供改变光连接的执行能力。要自动选路和恢复，还需要网管或控制功能、真实存在的其他线路、沿途可用的频谱与端口，以及满足接收要求的光信号质量。

路径经过更多光纤和 WSS，可能增加损耗、噪声和滤波影响；损耗是光功率减少，滤波影响可能使信号的部分频谱被削弱。不能仅凭“线路能连通”就确定数据能正确接收，也不能把每次改接都视为无中断切换。
