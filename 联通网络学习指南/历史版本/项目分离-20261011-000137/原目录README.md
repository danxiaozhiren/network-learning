# 网络知识笔记

这是一个面向网络基础学习与授课整理的 Markdown 笔记库，目前重点覆盖 IPv4 地址计算、子网掩码、CIDR、等长子网划分和 VLSM 规划。

内容更偏向可讲、可练、可复盘的课堂材料，适合用于运营商网络建设、维护、优化等场景中的地址规划基础训练。

## 建议学习顺序

1. 先读 [IP地址计算——从二进制到子网划分.md](./IP地址计算——从二进制到子网划分.md)，建立从二进制、掩码到子网划分的完整框架。
2. 再读 [子网掩码与VLSM课堂笔记.md](./子网掩码与VLSM课堂笔记.md)，重点吃透网络边界、块大小和 VLSM 分配步骤。
3. 最后自己手算几组地址规划题，再用子网计算器校验结果。计算器只用于验证，不建议一开始就依赖。

## 维护约定

- 新增笔记优先保持 Markdown 格式，文件名使用清晰中文标题。
- 涉及地址计算时，尽量同时写出计算过程、结论和可验证示例。
- 课堂材料和速查材料可以分开整理，避免一篇文档同时承担太多用途。
- 如果新增专题，建议同步更新本 README 的内容索引和学习顺序。
