## 1. 开场：从隔离到互通，再到远行（5 分钟）

**回顾前情**：
我们已经学会了用 VLAN 隔离广播域，用 Trunk 让 VLAN 跨交换机延伸。但隔离不是目的，业务需要互通——财务部要访问服务器，不同楼层的小区用户要互相通信。同时，为了提高可靠性，我们往往会部署冗余链路，但冗余可能带来环路灾难。

**今天的三步走**：
- **第一步**：简单认识一下二层环路与生成树协议（STP）——它是如何防止环路的，但我们不做深究。
- **第二步**：打破 VLAN 的隔离——用三层交换机上的 VLANIF 接口给每个 VLAN 配置网关，实现 VLAN 间高速路由。
- **第三步**：让数据包走出交换机，跨越路由器到达远端网络——通过静态路由手动告诉设备“往哪走”。

**课程目标**：学完后，你不仅能配置跨 VLAN 通信，还能让不同园区的 PC 通过多台路由器互 Ping，并理解路由表的本质。

## 2. 背景补充：二层环路与 STP 简介（10 分钟）

### 2.1 二层环路的危害
当交换机之间通过冗余链路形成物理环路时，广播帧会被反复转发，引发：
- **广播风暴**：广播帧指数级增长，占满带宽和 CPU。
- **MAC 地址表漂移**：同一 MAC 从不同端口收到，导致转发表震荡。
- **多帧复制**：同一数据帧可能经多条路径到达目的，上层协议无法处理。

### 2.2 STP/RSTP 的核心思想
- **生成树协议（STP，IEEE 802.1D）** 通过交换机之间交互 BPDU（桥协议数据单元），选举出一个“根桥”，并在逻辑上阻塞冗余端口，将环状拓扑修剪为一棵无环的树。
- **RSTP（快速生成树，IEEE 802.1w）** 在此基础上实现更快收敛，并引入边缘端口概念，避免终端接入触发拓扑变更。
- 在现网中，我们通常手动指定根桥位置，并在连接终端的端口启用边缘端口。

> **说明**：生成树协议是二层网络的“断路器”，本课仅做概念性了解，后续有专门课程深入。本次实验我们直接启用 RSTP 来消除环路，重点放在三层路由部分。

## 3. VLAN 间路由：让不同 VLAN 的主机通信（25 分钟）

### 3.1 为什么需要三层设备？
- 不同 VLAN 是**不同的广播域**，即不同的二层网络。跨 VLAN 通信本质是**跨网段通信**，必须经过路由——由三层设备（路由器或三层交换机）查路由表转发。
- 三层设备作为各 VLAN 的**网关**，从一个 VLAN 收到 IP 包后，剥掉二层帧头，查路由表，再重新封装成目的 VLAN 的二层帧头发送。

### 3.2 两种实现方式对比

| 方式 | 原理 | 优点 | 缺点 | 现网应用 |
|------|------|------|------|----------|
| **单臂路由** | 路由器的一个物理接口通过 Trunk 连接交换机，创建多个子接口，每个子接口对应一个 VLAN 并配置网关 IP | 无需三层交换机，利用现有路由器 | 所有跨 VLAN 流量共享一个物理链路，成为瓶颈；转发性能依赖 CPU | 小型企业网或临时调试 |
| **VLANIF（SVI）** | 三层交换机内部创建 VLANIF 接口，为每个 VLAN 配置 IP 地址作为网关 | 线速转发，性能高，配置简单 | 需要三层交换机硬件支持 | 汇聚/接入层主流方案 |

**本课重点**：VLANIF（交换虚拟接口），是现网最常用的方式。

### 3.3 VLANIF 接口配置要点
- **创建 VLAN** 并将端口划入对应 VLAN（Access 口）。
- **创建 VLANIF 接口**并配置 IP 地址作为该 VLAN 的网关。
- **VLANIF 接口 UP 的必要条件**（排障重点）：
  1. 该 VLAN 必须存在（已通过 `vlan batch` 创建）。
  2. 该 VLAN 下**至少有一个物理端口处于 Up 状态**（Access 口划入且端口 Up，或 Trunk 口允许该 VLAN 通过且端口 Up）。
  3. 若没有任何激活端口，VLANIF 接口状态为 Down，PC 无法 Ping 通网关。

**示例配置**（三层交换机）：
```system-view
[SW] vlan batch 10 20
[SW] interface Ethernet0/0/1
[SW-Ethernet0/0/1] port link-type access
[SW-Ethernet0/0/1] port default vlan 10
[SW] interface Ethernet0/0/2
[SW-Ethernet0/0/2] port link-type access
[SW-Ethernet0/0/2] port default vlan 20
[SW] interface Vlanif 10
[SW-Vlanif10] ip address 192.168.10.1 24
[SW] interface Vlanif 20
[SW-Vlanif20] ip address 192.168.20.1 24
```
配置完成后，VLAN 10 的 PC（网关 192.168.10.1）与 VLAN 20 的 PC（网关 192.168.20.1）即可互通，因为三层交换机内部自动生成直连路由。

## 4. 静态路由：让数据包走向远端网络（25 分钟）

### 4.1 路由表与最长匹配原则
- 路由表是网络设备转发数据包的“地图”，每条记录包含**目的网段、下一跳、出接口**等。
- 路由来源有三种：直连路由（自动）、静态路由（手动配置）、动态路由（协议学习）。
- **最长匹配原则**：当目的 IP 匹配多条路由条目时，选择**掩码最长（最精确）**的那条。这是排障时的核心思维。

### 4.2 静态路由配置
华为命令格式：
```system-view
[Router] ip route-static 目的网段 掩码 {下一跳IP | 出接口} [优先级]
```
- **下一跳 IP**：对端路由器的接口 IP（最常用）。
- **出接口**：用于点对点链路（如串口）。
- **优先级**：默认 60，数值越小越优先。

**示例**：R1 要去往 192.168.20.0/24，下一跳为 10.0.0.2：
```system-view
[R1] ip route-static 192.168.20.0 24 10.0.0.2
```

### 4.3 缺省路由（默认路由）
- 匹配所有目的地址（0.0.0.0/0），当路由表中没有更精确匹配时使用。
- 配置：`ip route-static 0.0.0.0 0 下一跳IP`
- **典型应用**：出口网关指向运营商，将所有外网流量送出。

### 4.4 浮动静态路由（备份）
- 配置两条去同一目的地的静态路由，优先级不同（如 60 和 80）。
- 主用链路失效后，备用自动生效，实现链路备份。
```system-view
[R1] ip route-static 192.168.20.0 24 10.0.0.2 preference 60
[R1] ip route-static 192.168.20.0 24 10.0.0.6 preference 80
```

### 4.5 静态路由的注意事项
- **双向性**：必须配置去程和回程路由，否则通信是单向的（Ping 请求超时）。
- **路由黑洞**：下一跳不可达时，匹配该路由的数据包会被丢弃，需避免错误指向。
- **环路风险**：两台路由器互指下一跳形成环路，数据包 TTL 耗尽。

## 5. eNSP 综合实验：VLANIF + 静态路由实现全网互通（30 分钟）

### 5.1 实验拓扑
```
[PC1]---(VLAN10)---[三层交换机 SW]---(Trunk)---[路由器 R1]---(10.0.0.0/30)---[路由器 R2]---(VLAN20)---[PC2]
                                                       |
                                                       +---(192.168.30.0/24)---[PC3]
```
- **SW** 为三层交换机，连接 PC1（VLAN 10）和 PC3（VLAN 30），同时通过 Trunk 上联 R1。
- **R1** 与 **R2** 之间用 10.0.0.0/30 互联。
- **R2** 下挂 PC2（VLAN 20，此处用二层交换机模拟，但为简化可直接用路由器接口连接 PC）。

**IP 规划**：
- PC1：192.168.10.10/24，网关 192.168.10.1（SW 的 Vlanif10）
- PC3：192.168.30.10/24，网关 192.168.30.1（SW 的 Vlanif30）
- SW 与 R1 互联：SW 的 Vlanif100：192.168.100.1/24，R1 的 G0/0/0：192.168.100.2/24（Trunk 允许 VLAN 10,30,100）
- R1 与 R2 互联：R1 G0/0/1：10.0.0.1/30，R2 G0/0/0：10.0.0.2/30
- R2 下接 PC2：R2 G0/0/1：192.168.20.1/24，PC2：192.168.20.10/24，网关 192.168.20.1

### 5.2 配置步骤

#### （1）配置三层交换机 SW
```system-view
[SW] vlan batch 10 30 100
[SW] interface Ethernet0/0/1
[SW-Ethernet0/0/1] port link-type access
[SW-Ethernet0/0/1] port default vlan 10
[SW] interface Ethernet0/0/2
[SW-Ethernet0/0/2] port link-type access
[SW-Ethernet0/0/2] port default vlan 30
[SW] interface Ethernet0/0/3
[SW-Ethernet0/0/3] port link-type trunk
[SW-Ethernet0/0/3] port trunk allow-pass vlan 10 30 100
[SW] interface Vlanif 10
[SW-Vlanif10] ip address 192.168.10.1 24
[SW] interface Vlanif 30
[SW-Vlanif30] ip address 192.168.30.1 24
[SW] interface Vlanif 100
[SW-Vlanif100] ip address 192.168.100.1 24
```
此时 SW 上已有直连路由：192.168.10.0/24、192.168.30.0/24、192.168.100.0/24。

#### （2）配置路由器 R1
```system-view
[R1] interface GigabitEthernet0/0/0
[R1-GigabitEthernet0/0/0] ip address 192.168.100.2 24
[R1] interface GigabitEthernet0/0/1
[R1-GigabitEthernet0/0/1] ip address 10.0.0.1 30
```
R1 上直连网段：192.168.100.0/24、10.0.0.0/30。  
添加去往 PC1（192.168.10.0/24）和 PC3（192.168.30.0/24）的静态路由：
```system-view
[R1] ip route-static 192.168.10.0 24 192.168.100.1
[R1] ip route-static 192.168.30.0 24 192.168.100.1
```
添加去往 PC2（192.168.20.0/24）的静态路由：
```system-view
[R1] ip route-static 192.168.20.0 24 10.0.0.2
```

#### （3）配置路由器 R2
```system-view
[R2] interface GigabitEthernet0/0/0
[R2-GigabitEthernet0/0/0] ip address 10.0.0.2 30
[R2] interface GigabitEthernet0/0/1
[R2-GigabitEthernet0/0/1] ip address 192.168.20.1 24
```
R2 上直连网段：10.0.0.0/30、192.168.20.0/24。  
添加回程路由，指向 R1 的互联接口：
```system-view
[R2] ip route-static 192.168.10.0 24 10.0.0.1
[R2] ip route-static 192.168.30.0 24 10.0.0.1
[R2] ip route-static 192.168.100.0 24 10.0.0.1
```

#### （4）验证互通
- PC1（192.168.10.10）Ping PC2（192.168.20.10）——应通。
- PC1 Ping PC3（192.168.30.10）——在同一台三层交换机上，经 VLANIF 直连路由转发，应通。
- 在 PC1 上执行 `tracert 192.168.20.10`，路径：PC1 → SW（网关）→ R1（192.168.100.2）→ R2（10.0.0.2）→ PC2，展示逐跳转发。

#### （5）扩展：配置缺省路由与浮动路由
- 在 SW 上配置缺省路由指向 R1，让所有未知流量上送：
  ```system-view
  [SW] ip route-static 0.0.0.0 0 192.168.100.2
  ```
  这样 SW 无需逐个配置远端网段路由（但本实验中已配置了具体路由，可删除具体路由，改用缺省，简化配置）。

- 在 R1 上配置浮动静态路由作为备份（假设还有第二条链路），例如：
  ```system-view
  [R1] ip route-static 192.168.20.0 24 10.0.0.2 preference 60   // 主用
  [R1] ip route-static 192.168.20.0 24 10.0.0.6 preference 80   // 备用（需实际存在）
  ```

#### （6）观察 VLANIF 接口状态
- 在 SW 上关闭连接 PC1 的端口（E0/0/1），观察 Vlanif10 状态变为 Down/Down（因为 VLAN 10 无激活端口）。
- 恢复端口后状态 Up，通信恢复。此实验帮助理解 VLANIF 依赖物理端口的特性。

## 6. 现网深度关联：运营商场景中的应用（10 分钟）

### 6.1 VLANIF 在汇聚层的应用
- 宽带城域网中，汇聚交换机下挂多个小区接入交换机，每个小区（或每栋楼）使用独立 VLAN。汇聚交换机配置 VLANIF 接口作为各 VLAN 网关，实现小区间互通，并上行至核心路由器。
- 基站回传场景：将 S1-U（用户面）、S1-C（控制面）、OAM 分属不同 VLAN，在回传设备上通过 VLANIF 终结，路由到核心网不同网元。

### 6.2 静态路由在出口与核心层的应用
- 企业出口或 BRAS 设备配置缺省路由指向核心网，将所有出网流量送往上联设备。
- 核心层与汇聚层之间，当拓扑简单稳定时，常用静态路由互指，避免运行动态协议的开销。
- 华为设备支持 **NQA（网络质量分析）** 与静态路由联动，当探测到下一跳不可达时自动失效，配合浮动路由实现快速切换，弥补静态路由无法感知链路故障的缺陷。

### 6.3 常见故障排查
- **VLANIF 接口 Down**：检查该 VLAN 是否存在，物理端口是否 Up（包括 Trunk 口是否允许该 VLAN）。
- **跨 VLAN 不通**：检查 PC 网关是否正确配置，交换机上 VLANIF 是否存在且 UP。
- **跨路由器不通**：检查路由表是否有去往目的网段的路由，注意回程路由是否缺失（Ping 请求超时）。使用 `display ip routing-table` 查看匹配情况，利用最长匹配原则分析。

## 7. 课堂小结与课后任务（5 分钟）

**核心回顾**：
- 二层环路通过 STP/RSTP 解决（本课仅作了解）。
- VLAN 间通信必须经过三层路由，VLANIF（SVI）是现网主流方案，配置简单且线速转发。
- 静态路由手动指定去往非直连网段的路径，缺省路由简化出口配置，浮动路由实现备份。
- 路由查询遵循最长匹配原则，排障时务必检查路由表的双向可达性。

**课后任务（eNSP）**：
1. 完成本课综合实验，验证 PC1、PC2、PC3 三者互通。
2. 在三层交换机 SW 上配置缺省路由替代具体路由，观察通信是否仍正常。
3. 在 R1 上故意删除去往 PC2 网段的静态路由，观察 PC1 Ping PC2 的现象，再恢复配置，体会路由缺失的影响。
4. 思考题：若三层交换机上某个 VLAN 仅有一个 Trunk 口上联，且该 Trunk 口 Up，但下联没有任何 PC，此时 VLANIF 接口状态是 Up 还是 Down？为什么？（答案：Up，因为 Trunk 口允许该 VLAN 且端口 Up，满足物理激活条件。）
